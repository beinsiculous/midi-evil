MIDI Evil

A music workstation in the browser. Tab into the editor; what it has focused is written under it. The editor takes the keys below and no others, so every other chord stays the browser's.

Keyboard notes

Anywhere

  • Control+S: saves the project
  • Control+Z: undoes the last edit
  • Control+Shift+Z: redoes it
  • Control+Y: redoes it
  • Space: plays or stops the song, where the focused control does not take Space
  • Alt+Page Down: the next region: the toolbar, the side panel, the editor
  • Alt+Page Up: the region before

Song (the arranger)

  • Left: previous part, then the track's unique timeline
  • Right: next part
  • Up: track above, at the same point in the song
  • Down: track below, at the same point in the song
  • Home: the track's unique timeline
  • End: the track's last part
  • Control+Left: moves the part a bar earlier
  • Control+Right: moves the part a bar later
  • Enter: opens it in the piano roll
  • Delete: removes the part
  • B: starts playback at the part's first bar
  • I: reads the transport

Piano roll

  • Left: previous note
  • Right: next note
  • Home: first note
  • End: last note
  • Up: a semitone higher
  • Down: a semitone lower
  • Shift+Up: an octave higher
  • Shift+Down: an octave lower
  • Control+Left: moves the note earlier
  • Control+Right: moves the note later
  • Shift+Left: shorter
  • Shift+Right: longer
  • Enter: adds a note
  • Delete: removes the note
  • Escape: clears the selection
  • I: reads the transport
