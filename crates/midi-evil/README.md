# MIDI Evil

A Rust desktop music workstation for original synthesis, drum performance, Standard MIDI, editable `.evil` projects, and offline stereo WAV export.

Run from a source checkout with `cargo run -p midi-evil`, or install this package with `cargo install midi-evil` once published. See the [project README](https://github.com/magicjedi90/midi-evil#readme) for workflows and verification instructions.
